# トークモニター β

インサイドセールス（電話営業）の通話を、**録音を入れるだけ**で文字起こしし、トークの質を8項目で判定するブラウザツールです。文字起こしを貼るだけでも使えます。

**公開ページ**：https://kidlife19.github.io/talk-monitor/

> note「サイレントインベスター」の 100日チャレンジ（AIくんと相談してコールしたらこうなった）で使っているツールです。
> 記事：（ここに note のURLを入れる）

## なぜ作ったか

IS（インサイドセールス）の現場で11年、新人のトークを聞いて直す側に立ってきました。録音を全部聞き直す時間はなく、指摘も人によってぶれます。そこで「何を言えていれば合格か」をルールに落とし、文字起こしから機械的に判定できるようにしました。

## 判定する8項目

| 区分 | 項目 | 見ていること |
|---|---|---|
| スクリプト | 数値 | 導入社数・削減率など、決めた数字を言えたか |
| | 目的 | 電話の目的を最初に伝えたか |
| | プロダクト | 商品名を言ったか |
| | アポ日付 | 日付と時間の両方まで打診したか |
| 敬語 | 二重敬語・冗長な敬語 | 「おっしゃられる」「よろしかったでしょうか」など。BtoBでは過剰な敬語は減点 |
| | 謝罪の回数 | 「申し訳ありません」は2回まで |
| 情報の確保 | 名前 | 相手の名前を聞いて復唱したか |
| | メールアドレス | アドレスを取れたか |

合格ラインは「8項目中6項目」。現場の新人は打たれ弱いことが多いので、最初から満点を求めず、慣れてきたら上げる設計にしています。不合格の表示は「もう一度やろうか？」です。

クレームや言葉が荒い相手は「イレギュラー」として別扱いにし、スクリプトの項目は見ずに「短く『ありがとうございました』で切れたか」だけを判定します。

## 料金を聞かれたときの基準（説明の逸脱チェック）

- **ベスト**：金額には踏み込まず、オンラインの打ち合わせに誘導する
- **ベター**：合っていることを分かる範囲で話し、詳しくはオンラインの打ち合わせへ
- **NG**：「無料です」だけで終わる／スクリプトにない金額・条件・断定を言う／料金の質問を無視して進める

## 録音から文字起こし（ブラウザ内で完結）

- m4a・mp3・wav を画面にドラッグするだけで文字起こしし、そのまま判定します。
- 文字起こしは **ブラウザの中** で行い、録音はどこにも送りません。日本語音声認識モデル ReazonSpeech k2 v2（int8）を ONNX Runtime Web で動かしています。
- 初回だけモデル（約160MB）を読み込み、2回目からはブラウザに残ります。PC の Chrome / Edge 推奨。
- 無音（0.4秒以上）で区切った単位で1行にします。左右のチャンネルが別々の話者のステレオ録音なら、左を営業、右を相手として分けます。

## 構成

```
src/
  engine.js   判定エンジン。DOMに触らない純粋関数だけで、ブラウザでもNodeでも動く
  demo.js     架空のプロダクトとサンプル通話（NG例・OK例・クレーム例）
  index.html  画面（文字起こし貼り付け版）
test/
  engine.test.js  サンプル通話で判定結果を確かめるテスト
docs/           公開ページ（GitHub Pages）。録音からの文字起こしつきの最新版
  index.html
  asr/          文字起こし（worker.js・core.js・ONNX Runtime Web・モデル）
```

判定ロジックを画面から切り離しているので、ルールを変えたときはテストで挙動を確かめてから画面に反映できます。

## 使い方

公開ページを開くだけで動きます。録音ファイルを選ぶか、文字起こしを貼ると判定が出ます。サンプル通話のボタンで、NG例・OK例・クレーム例も試せます。

辞書・ルール・履歴は、このブラウザの中に保存されます（別のPCやブラウザには引き継がれません）。

手元で動かすときは、`docs` フォルダで `python -m http.server` を実行して `http://localhost:8000` を開きます（`index.html` を直接ダブルクリックすると、文字起こしは動きません）。

テスト（Node 18 以上）:

```
npm test
```

## 工夫した点

- **録音をそのまま入れられる**：文字起こしツールを別に用意しなくても、録音から判定まで1画面で終わる。録音は外に出さない
- **専門用語の辞書**：音声認識の誤り（「アイブイアール」→「IVR」）を正式な用語に読み替えてから判定する。業界ごと・プロダクトごとに育てていける
- **数字の表記ゆれ**：「三千社」「3千社」「3,000社」を同じものとして扱う
- **話者の自動判別**：「営業:」「相手:」のようなラベルから、どちらが営業担当かを推定する
- **料金対応の判定**：料金を聞かれたときの答え方を、ベスト／ベター／NGで見る
- **AI講評**（claude.ai 上で開いたときのみ）：その通話の文言だけを根拠に、言い換え案を出す
