# トークモニター β

インサイドセールス（電話営業）の通話の文字起こしを貼るだけで、トークの質を8項目で判定するブラウザツールです。

## なぜ作ったか

IS（インサイドセールス）の現場で11年、新人のトークを聞いて直す側に立ってきました。録音を全部聞き直す時間はなく、指摘も人によってぶれます。そこで「何を言えていれば合格か」をルールに落とし、文字起こしから機械的に判定できるようにしました。

## 判定する8項目

| 区分 | 項目 | 見ていること |
|---|---|---|
| スクリプト | 数値 | 導入社数・削減率など、決めた数字を言えたか |
| | 目的 | 電話の目的を最初に伝えたか |
| | プロダクト | 商品名を言ったか |
| | アポ日付 | 日付と時間の両方まで打診したか |
| 敬語 | 二重敬語・冗長な敬語 | 「おっしゃられる」「よろしかったでしょうか」など。BtoBでは過剰な敬語は減点 |
| | 謝罪の回数 | 「申し訳ありません」は2回まで |
| 情報の確保 | 名前 | 相手の名前を聞いて復唱したか |
| | メールアドレス | アドレスを取れたか |

合格ラインは「8項目中6項目」。現場の新人は打たれ弱いことが多いので、最初から満点を求めず、慣れてきたら上げる設計にしています。不合格の表示は「もう一度やろうか？」です。

クレームや言葉が荒い相手は「イレギュラー」として別扱いにし、スクリプトの項目は見ずに「短く『ありがとうございました』で切れたか」だけを判定します。

## 構成

```
src/
  engine.js   判定エンジン。DOMに触らない純粋関数だけで、ブラウザでもNodeでも動く
  demo.js     架空のプロダクトとサンプル通話（NG例・OK例・クレーム例）
  index.html  画面（モニタリング／辞書・ルール／履歴の3タブ）
test/
  engine.test.js  サンプル通話で判定結果を確かめるテスト
```

判定ロジックを画面から切り離しているので、ルールを変えたときはテストで挙動を確かめてから画面に反映できます。

## 使い方

`src/index.html` をブラウザで開くだけで動きます。サンプル通話のボタンで、NG例・OK例・クレーム例の判定を試せます。

単体で開いた場合、登録した辞書や履歴は画面を閉じると消えます（保存先につながっているときだけ残ります）。

テスト（Node 18 以上）:

```
npm test
```

## 工夫した点

- **専門用語の辞書**：音声認識の誤り（「アイブイアール」→「IVR」）を正式な用語に読み替えてから判定する。業界ごと・プロダクトごとに育てていける
- **数字の表記ゆれ**：「三千社」「3千社」「3,000社」を同じものとして扱う
- **話者の自動判別**：「営業:」「相手:」のようなラベルから、どちらが営業担当かを推定する
- **AI講評**（保存先・AIにつながっている環境のみ）：その通話の文言だけを根拠に、言い換え案を出す
